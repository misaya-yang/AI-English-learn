# VocabDaily 全面 UI 走查与升级总纲

> 日期：2026-07-16
> 分支：`dev_0716`
> 模式：现有产品 Upgrade
> 视觉主线：雾蓝编辑式学习工作台（Mist-blue Editorial Learning Workbench）
> 完成状态：已实施、已完成五档视口全量走查

## 1. 目标与边界

本轮不是重新发明一个新产品，而是在保留现有学习逻辑、文案契约、i18n、路由和数据层的前提下，完成一次覆盖全产品的 UI 系统升级。

最终必须同时满足：

1. 29 个稳定用户页面全部纳入走查与验收，不能只改首页或抽样页面。
2. `/auth/callback` 与 `/dashboard` 两个过渡/重定向路由有明确、可恢复的状态。
3. 首屏优先展示真实任务、数据、输入区或下一步，不靠大片留白营造“高级感”。
4. 普通侧栏 Link、普通卡片 Link 不再显示没有信息价值的 `>` / Chevron；只在真实展开、层级钻取、上一项/下一项中保留方向符号。
5. 不再用“去掉边框和背景，但保留原卡片 padding/gap”的方式制造隐形卡片岛。
6. 动效只服务层级、连续性、反馈和氛围；不让每张卡、每个按钮统一漂浮或缩放。
7. 移动端必须重新编排，不能只是桌面布局缩小。
8. 修复走查中发现的前端真实性、状态、可访问性、滚动和性能问题。

## 3. 设计主线

### 3.1 一个视觉记忆点

VocabDaily 应像一张有明确学习顺序的编辑式工作台：

- 雾蓝画布负责环境；
- 接近纸张的浅色内容面负责阅读和练习；
- 墨色标题负责结构；
- 蓝色只标记当前动作、选择和进度；
- 绿、黄、红只表达学习结果与风险；
- 导航和浮层可以保留轻量玻璃感，正文不再玻璃化。

### 3.2 支撑母题

1. **编辑式层级**：标题、导语、任务、证据和下一步有明显阅读顺序。
2. **开放式分组**：优先用对齐、留白、细分隔线和色调分区组织内容。
3. **真实学习内容**：用词、题、进度、错题和行动填充首屏，不增加假指标或装饰插图。

### 3.3 负面约束

禁止：

- 无意义 Chevron、孤立装饰图标、重复方向提示；
- 大面积空白配小内容岛；
- 每个内容块都包卡片；
- 全局 hover 统一缩放；
- 永久 `will-change`；
- 所有页面同时执行入场 stagger；
- 用假保存、假通知、假邮件、假结账或假排行榜制造“完整感”；
- 新增泛化 AI 渐变、光晕、Blob 或 Bento 模板。

## 4. 全局实施合同

### 4.1 颜色与表面

- 拉开 canvas、paper、raised、sunken 四级明度差。
- 内容面从当前接近背景的雾蓝，调整为更清晰的纸面浅色。
- `liquid-glass` 只保留在导航、菜单、Popover、Sheet、Dialog 等浮层。
- 普通控件不再使用高成本 backdrop blur。
- 每个页面最多一个主要 surfaced shell，内部尽量平铺。

### 4.2 字体与密度

- 页面标题统一使用 `focus-page-title` / display role。
- 中文标题不再与英文副标题机械堆叠。
- 桌面正文主区目标宽度按页面类型落在 1180–1360px。
- 减少重复页头、重复 KPI 和重复说明。
- 1440 × 900 下，去除壳层后至少约 65% 的可视高度应由真实任务、数据、输入或结果占据。

### 4.3 边界政策

- 普通内容组：开放布局或单侧分隔线。
- 输入、破坏性动作、表格、复杂筛选：保留持久边界。
- Hover：轻色调变化或最多上移 1px。
- Selected：持久色调、标记或对比，不只靠阴影。
- Focus：必须比 Hover 更明确。
- Pressed：回到画布，不继续上浮。

### 4.4 动效预算

| 场景 | 时长 | 机制 |
|---|---:|---|
| 按钮、选择、直接反馈 | 120–180ms | CSS tonal transition |
| 内容/状态切换 | 180–280ms | CSS 或现有 Framer Motion |
| Sheet / Dialog 进入 | 200–240ms | 现有 Radix / motion |
| Sheet / Dialog 退出 | 140–180ms | 现有 Radix / motion |
| Home 主叙事进入 | 420–720ms 总时长 | 一次有界 stagger |
| BottomNav active pill | 保留单一 spring | Framer layoutId |

规则：

- 页面路由切换仅做 6–8px、约 240ms 的轻入场。
- 只保留 BottomNav 一套 spring；普通导航使用 tonal transition。
- 错误 shake 最多一次、≤180ms。
- Confetti 只在整组完成时触发一次、≤1.2s。
- reduced-motion 下内容立即可见，取消位移、parallax、confetti、循环 shimmer 和 smooth scroll。

### 4.5 响应式合同

必须验收：

- 1440 × 900
- 1280 × 800
- 768 × 1024
- 390 × 844
- 390 × 667

移动端硬要求：

- 真实操作对象进入首屏；
- 触控目标至少 44 × 44；
- 固定底栏不遮挡内容；
- 无内部横向溢出；
- 长 CTA 可换行；
- 不保留桌面双栏几何；
- Sheet 导航后自动关闭并恢复正确焦点。

## 6. 路由级优化方案

### 6.1 公共与营销

#### `/` Home

问题：

- Hero 左侧三条任务与右侧 Today preview 重复；
- Home 自绘品牌头，与其他公共页不一致；
- 移动端 844px 只能看到 Today preview 开头；
- 样例词标题右侧 BookOpen 是孤立装饰；
- 页面完全静态，缺少一次明确的 arrival。

方案：

- 只保留一份 Today preview。
- CTA 后直接进入 compact Today preview，移动端首屏完整显示主动作与计划摘要。
- 复用 BrandMark / PublicHeader。
- headline → copy → CTA → preview 做一次 60–90ms stagger。
- 其余区段静止或仅首次进入淡入。

#### `/pricing`

问题：

- Coming soon 重复出现多次；
- 匿名用户显示“当前方案”；
- 1440 下右侧闲置明显；
- live billing 分支仍是死 CTA；
- waitlist 只写 localStorage，却承诺通知。

方案：

- 12 栏排版：Hero/状态 7/5，Plan 两列占满。
- Coming soon 只在 Pro 卡保留一次。
- 未登录不显示“当前方案”。
- 未接后端时使用诚实文案，不出现“会通知/可结账”。
- 周期切换只做数字 crossfade/layout transition。

#### `/demo`

问题：

- 左侧先展示完整答案，右侧 recall 失去意义；
- “保存进度”并未保存；
- 错误态使用 Check 图标；
- 桌面下半屏大片空白。

方案：

- 改成 prompt → input → feedback 的单一 workbench。
- 提交前只给语义线索，不展示完整答案。
- 反馈原位展开，避免页面跳动。
- 未实现持久化时改成诚实的“继续到今日”。
- 390px 首屏包含输入和主按钮。

#### `/word-of-the-day`

问题：

- 移动端缺主题/语言入口；
- Tab 内容固定高 ScrollArea，形成嵌套滚动；
- 今日词与历史词共用 activeTab；
- 音频、上一词、下一词缺 accessible name；
- 匿名页加载完整 UserDataProvider，LCP 负担偏大。

方案：

- 移动端 More 菜单保留主题/语言。
- 内容自适应高度，取消固定内滚动。
- 今日词和历史 Dialog 使用独立 tab state。
- 所有 icon-only action 命名。
- 条件加载登录后动作。

#### `/terms` 与 `/privacy`

问题：

- 固定“返回注册”，上下文错误；
- 两页缺互链与目录；
- Privacy 使用条款式副标题；
- 宽屏正文过窄，靠两侧留白支撑。

方案：

- 3/9 editorial grid：左侧目录与元信息，右侧正文。
- 移动端 Terms/Privacy segmented links。
- 返回动作优先 history，fallback Home。
- 邮箱改为可点击 `mailto:`。
- 页面近静态，不加装饰动效。

### 6.2 认证与引导

#### `/login`

问题：

- AuthShell 两个小内容岛悬在大画布；
- 主题/语言控件与品牌、表单分离；
- 自制重置密码弹层缺 focus trap、Escape、焦点归还和 scroll lock；
- Demo 按钮图标隐喻错误。

方案：

- AuthShell 改为有边界的横向 workbench band。
- 顶部统一 Brand + Theme + Language。
- 左侧 Today preview 与品牌组合，右侧表单紧凑排列。
- Forgot password 使用 Radix Dialog。
- 移动端单列，trust strip 放表单下方。

#### `/register`

问题：

- 同 AuthShell 留白；
- 密码规则文案与实际校验/i18n 不一致；
- 输入未绑定规则说明；
- 法律链接离开后可能丢表单。

方案：

- 实时 password checklist 与 `aria-describedby`。
- 同步当前 8 字符、大小写、数字、特殊字符规则。
- 保留 redirect 与表单草稿。
- 明确注册后是邮箱验证还是直接 onboarding。

#### `/magic-link`

问题：

- 当前是假发送；
- 短表单垂直居中后留白最明显。

方案：

- 调用真实 OTP API，提供失败和重发冷却。
- 如环境不支持，诚实禁用入口，不显示已发送。
- sent 状态只做局部 icon/opacity transition。

#### `/auth/callback`

问题：

- 失败直接跳 Login，没有可恢复状态；
- 无 timeout；
- effect 依赖本地化文案，切语言可能重跑。

方案：

- 独立 verifying → success → error 状态。
- 错误态提供重试和返回登录。
- effect 稳定执行一次，增加 timeout/settled guard。
- loader 使用 `role="status"` / `aria-live`。

#### `/onboarding`

问题：

- 移动端重复标题和大装饰图标占首屏；
- Next 在首屏以下；
- 切步无 heading focus；
- 刷新丢步骤；
- Placement 选择语义不足。

方案：

- 顶部只保留 step label、progress 和一句说明。
- 删除每步无意义大图标。
- 移动底部 sticky Back/Next。
- 切步 240–320ms 方向性 continuity，结束后 focus 新标题。
- Placement 使用 radiogroup/fieldset。

### 6.3 核心学习闭环

#### `/dashboard/today`

问题：

- 移动端任务摘要把真实单词推到首屏以下；
- 跨午夜不自动刷新 dayKey；
- currentWordIndex 未随列表 clamp；
- timer/confetti 清理不足；
- 快捷键会抢占按钮、链接和 contenteditable；
- clipboard 失败未处理。

方案：

- 移动端任务摘要压成单行 progress strip，真实单词立即出现。
- 桌面维持主工作区 + 280px rail，并扩大总宽度。
- 词切换 180–220ms、8px 内的可中断过渡。
- 修复日期、索引、timer、快捷键和 clipboard 状态。

#### `/dashboard/review`

问题：

- 外层 `role=button` 内嵌 Audio Button；
- 音频按钮缺 accessible name；
- 评分无 lock，可连点重复写入；
- UI 固定显示间隔，与动态 FSRS 不一致；
- 360px 最小卡高导致移动首屏低效。

方案：

- Recall 区与 Audio Button 分离，Reveal 使用真实 button。
- 评分 transaction lock。
- 显示实际 FSRS interval。
- 移动端统计压成一行，headword 进入首屏。
- Reveal 160–200ms crossfade，下一卡 180ms。

#### `/dashboard/practice`

问题：

- Picker 有效内容只集中在左上，桌面大片空白；
- 题目队列可能随 progress 更新重建；
- listening effect 可能播放错误 index；
- timedMode reset/作用范围错误，且时间不可见；
- Writing 完成错记为 review task；
- quota/评分失败缺补偿；
- prompt 修改后仍沿用原 writingItemId；
- Promise rejection 捕获方式错误；
- 英文 UI 混入中文 insight。

方案：

- 明确 picker / ready / active / feedback / recap 状态机。
- Picker 使用真实当日词、模式、题数、预计时间填充首屏。
- 桌面改成紧凑的选中模式 + 模式列表组合，不保留大片空白。
- 冻结本轮 queue。
- Timer 仅 quiz/fill_blank 有效、常驻可见。
- 修复 Writing task、quota、provenance 和异步错误。

#### `/dashboard/chat`

问题：

- Dashboard 页头与 Chat 页头重复；
- 教练摘要、Roleplay、Daily Plan 挤压消息区；
- 中等桌面同时出现 App sidebar 和 Chat history；
- Composer 工具层短屏可能裁切；
- Enter 未检查 IME composing；

- 删除无确认；
- streaming 每帧 smooth scroll；
- 调试指标暴露过多。

方案：

- Roleplay 放入工具层，激活后才显示。
- `<1440px` History 使用 overlay Sheet。
- Composer 工具层可滚动，最大高度 `min(60dvh, 480px)`。
- 修复 IME、键盘、删除确认、autoscroll。
- 新消息只做 160ms 小位移，不重复动画整个历史。

#### `/dashboard/learning-path`

问题：

- 桌面“阶段索引 + lesson timeline”，移动端下一课进入首屏。
- metric grid 按实际项目数动态分列。
